# 카카오 알림톡 — 인계문 (2026-09-09 홀딩)

사용자 지시로 **홀딩**한다. 「우선 급한 것부터 작업 후 최종 릴리즈 버전 때 추가한다.」
PR #142(`claude/alimtalk-channel`)는 머지하지 않고 열어 둔다.

다시 꺼낼 때 처음부터 파지 않도록 알아낸 것만 남긴다.

## 3. 수신번호가 갈림길이다

나머지 다섯이 다 갖춰져도 번호가 없으면 한 건도 못 나간다.

- 번호의 유일한 출처는 `identity.identities.mobile`이다 — `packages/db/migrations/0059_social_profile.sql:10`.
- 그 값은 카카오 id_token의 `phone_number` 클레임으로만 채워진다 — `apps/api/src/auth/identity-provider.ts:91` → `apps/api/src/auth/sessions.ts:64`.
- **지금 로그인이 요청하는 동의항목은 둘뿐이다: `['openid', 'profile_nickname']`** — `apps/mobile/src/features/auth/providers.ts:171`. `phone_number`가 없다.
- 즉 번호가 안 들어오는 1차 원인은 비즈앱 여부 이전에 **동의항목을 아예 요청하지 않는 것**이다. 재개하면 이 줄부터 본다.
- 번호가 없을 때 문자로 대신 보내지 않는다(사용자 지시). 그 경우 푸시·알림함으로만 가고 이력에 `skip_reason='no_recipient'`로 남는다.

## 4. 아직 답 못 한 질문 — 재개하면 여기부터

**(1) 알림톡을 카카오가 직접 열어주는가.**
공개 문서로 확인한 범위에서는 **공식 딜러사(발송 대행사)를 거쳐야 하고** 그 전에 비즈니스 채널 심사가 필요하다. 물량 기준 직접 계약 예외가 있는지는 **확인 필요**.
→ 참이면 2·3·5번이 그대로 필요하다.

**(2) 카카오톡 메시지 API(나에게 보내기)로 6종 중 몇 개가 대행사 없이 나가는가.**
이게 참이면 **사전 준비 2~5번 넷이 통째로 사라지고 비용도 0이 된다.** 조사한 잠정 결론:

- 나에게 보내기는 `talk_message` 동의항목만 있으면 되고 검수·발송 제한이 없다(검색 결과 기준, 원문 직접 열람 못 함).
- 수신자가 본인인 5종(일정 D-1 · 인증 결과 · 당첨 · 계정 보안 · 탈퇴)은 될 것으로 보인다. **COUPLE_INVITE은 타인 수신이라 안 된다** — 친구에게 보내기는 권한 신청·검수 대상이고, 친구 API가 앱에 연결된 친구만 준다면 아직 앱을 깔지 않은 배우자에게는 성립하지 않는다(확인 필요).
- **숨은 값이 있다.** 나에게 보내기는 그 사용자의 액세스 토큰으로 부르는 API인데, 지금 서버는 카카오 토큰을 하나도 보관하지 않는다(`identity-provider.ts:133`에서 프로필 조회에 한 번 쓰고 버린다. `identity.identities`에 토큰 열이 없다). 워커가 나중에 보내려면 리프레시 토큰을 저장·갱신해야 하고, **액세스 6시간 · 리프레시 2개월**이라 **2개월 넘게 접속하지 않은 사람에게는 못 보낸다.** 알림톡에는 이 구멍이 없다.
- 카카오 개발자 콘솔의 「메시지 템플릿 구성」(피드 · 리스트 · 커머스)은 **이 메시지 API의 템플릿 등록처이고 알림톡과 다른 제품이다.** 이쪽으로 가면 `spec/alimtalk.templates.json`의 모양이 바뀐다(템플릿 구조가 다르다). 포트 · 정책 · 이력 표는 그대로 쓴다.

## 6. 이미 결정된 것 — 다시 논의하지 않는다

- **문안 정본은 `spec/`에 둔다.** 도메인 코드는 타입과 검증만 갖고 본문을 복사하지 않는다. 승인본 대조 테스트가 이를 지킨다.
- **정의는 6종 전부, 발송은 승인된 것만.** `approved`가 false면 알림톡을 건너뛰고 푸시 · 알림함만 탄다. 건너뛴 것은 실패가 아니라 `skipped`로 남긴다. 환경 게이트(비운영이면 무조건 차단)가 승인 플래그보다 앞이다.
- **버튼은 「다시 확인하기」**(WP_VERIFY_REJECTED). 본문 원문은 한 글자도 고치지 않는다. 본문 끝의 대괄호 줄은 카카오 콘솔에 등록할 때 버튼이 별도 필드인 것이 눈에 보이면 그때 뺀다.
- **실발송 드라이버는 `none` 고정.** 알림톡 실패 시 문자로 자동 전환하지 않는다.
- 여섯 이벤트는 서비스 필수 알림이라 하루 2건 한도를 세지 않는다.
